Dynamic programming is an optimization technique used in computer science to resolve complex issues by splitting them down into simpler, overlapping subproblems. In contrast to divide and conquer algorithms, which partition a problem into separate subproblems, dynamic programming applies when the subproblems intersect. By storing the results of these subproblems in a cache, an approach known as memoization, dynamic programming avoids redundant computations and significantly decreases the time complexity from exponential to polynomial.

In order to utilize dynamic programming, an issue must display two primary characteristics. First, it must have optimal substructure, indicating that the best solution to the main problem can be assembled from the best solutions to its subproblems. Second, it must feature overlapping subproblems, meaning the standard recursive algorithm would resolve the exact same subproblems multiple times.

Dynamic programming is an optimization approach used in computer science to solve complex problems by breaking them down into simpler, overlapping subproblems. Unlike divide and conquer algorithms, which partition a problem into disjoint subproblems, dynamic programming applies when the subproblems intersect. By caching the results of these subproblems in a table, an approach known as memoization or tabulation, dynamic programming avoids redundant computations and drastically reduces the time complexity from exponential to polynomial.

To apply dynamic programming, a problem must exhibit two main characteristics. First, it must have optimal substructure, meaning that an optimal solution to the overall problem can be constructed from optimal solutions to its subproblems. Second, it must feature overlapping subproblems, meaning the naive recursive algorithm would solve the same subproblems repeatedly.

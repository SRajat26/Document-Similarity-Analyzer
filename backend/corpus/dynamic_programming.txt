Dynamic programming is a powerful algorithmic technique used to solve optimization problems by breaking them down into simpler overlapping subproblems. Unlike divide and conquer, dynamic programming stores the results of subproblems to avoid redundant computations. This technique is applicable when a problem exhibits optimal substructure and overlapping subproblems.

The Fibonacci sequence is a classic example of dynamic programming. The naive recursive approach has exponential time complexity O(2^n), but with memoization or tabulation, it can be solved in O(n) time and O(n) space. The bottom-up tabulation approach fills a table iteratively, while the top-down memoization approach uses recursion with caching.

The longest common subsequence problem finds the longest sequence that appears in both input sequences in the same order but not necessarily contiguously. The dynamic programming solution builds a table of size m by n where m and n are the lengths of the two sequences. Each cell stores the length of the LCS of the corresponding prefixes. The time complexity is O(m * n) and the space complexity is also O(m * n), though it can be optimized to O(min(m, n)) if only the length is needed.

The knapsack problem is another classic dynamic programming problem. Given a set of items with weights and values, the goal is to maximize the total value while keeping the total weight within a capacity limit. The zero-one knapsack has a time complexity of O(n * W) where n is the number of items and W is the capacity. This is a pseudo-polynomial time algorithm because it depends on the magnitude of the input values.

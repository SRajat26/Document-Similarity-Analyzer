Greedy algorithms make locally optimal choices at each step with the hope of finding a global optimum. While greedy algorithms do not always produce optimal solutions, they work correctly for problems that exhibit the greedy choice property and optimal substructure. When these conditions are met, greedy algorithms often provide the most efficient solutions.

The activity selection problem is a classic example of a greedy algorithm. Given a set of activities with start and finish times, the goal is to select the maximum number of non-overlapping activities. The greedy approach sorts activities by finish time and iteratively selects the next compatible activity. This produces an optimal solution in O(n log n) time due to the sorting step.

Huffman coding is a greedy algorithm for data compression that assigns variable-length codes to characters based on their frequencies. Characters with higher frequencies receive shorter codes. The algorithm builds a binary tree by repeatedly merging the two nodes with the lowest frequencies using a priority queue. Huffman coding produces an optimal prefix-free code and is widely used in file compression formats.

The fractional knapsack problem can be solved optimally using a greedy approach. Items are sorted by their value-to-weight ratio, and items are added greedily starting with the highest ratio. Unlike the zero-one knapsack problem, fractions of items can be taken. The time complexity is O(n log n) for sorting. The coin change problem with standard denominations can also be solved greedily, though the general version requires dynamic programming.
